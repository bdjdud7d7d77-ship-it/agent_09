# PPT 규칙 (v1)

이 규칙은 이 프로젝트에서 PowerPoint(.pptx) 발표 자료를 만들거나 수정할 때마다 적용되며, `mk-ppt` 스킬을 사용할 때도 포함됩니다.

## 1. 기본 슬라이드 장수

- 기본적으로 **8장**의 슬라이드를 만듭니다.
- 사용자가 명시적으로 요청한 경우에만 다른 장수를 사용합니다.
- 제작 전에 슬라이드 장수에 맞춰 개요(각 슬라이드 제목 + 유형)를 구성합니다.

## 2. 디자인 참고

- 제작 전에 사용자가 제공한 디자인 `.md` 파일(색상, 폰트, 레이아웃, 톤 등)을 읽고 그대로 따릅니다.
- 디자인 파일이 `mk-ppt` 스킬의 기본 테마와 충돌하면 사용자의 디자인 파일을 우선합니다.
- 디자인 파일이 제공되지 않았다면 제작 전에 사용자에게 요청하고, 사용자가 원할 때만 `mk-ppt` 기본 테마를 사용합니다.

## 3. 가독성: 넘침 금지, 겹침 금지

- 글이 슬라이드나 텍스트 상자 밖으로 넘치지 않게 합니다.
- 글과 도형, 또는 도형끼리 겹쳐 가독성이 떨어지지 않게 합니다.
- 글은 짧게 유지합니다. 읽기 어려운 크기로 글꼴을 줄이는 대신 문구를 줄이거나, 글머리 개수를 줄이거나, 내용을 여러 슬라이드로 나눕니다.
- 제작 후 슬라이드를 이미지로 렌더링해 모든 슬라이드의 넘침, 겹침, 어색한 줄바꿈, 과밀 여부를 점검하고, 문제가 없어질 때까지 사양을 고쳐 다시 만듭니다.
