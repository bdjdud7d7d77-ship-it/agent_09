# 슬라이드 디자인 시스템 — "Orange Can-do"

`.pptx` 발표 자료 제작용 디자인 참고 문서입니다(`mk-ppt` 스킬과 함께 사용). 오렌지 비즈니스 템플릿(`슬라이드 템플릿.jpg`)을 바탕으로 합니다.

## 1. 콘셉트

- 깔끔하고 활기찬 비즈니스 톤: **흰 바탕 + 강한 오렌지 포인트 색 하나**.
- 여백과 가는 선을 넉넉히 쓰고, 색은 핵심 정보 강조에만 사용합니다.
- 슬라이드 비율 **16:9** (13.333 × 7.5 in).

## 2. 색상

| 토큰 | HEX | 용도 |
|---|---|---|
| `primary` | `#F26B1D` | 강조 바, 아이콘, 차트 채우기, 강조 행 |
| `primary-dark` | `#D9480F` | 섹션 라벨("CONTENTS A"), 강조 텍스트 |
| `primary-light` | `#FDE3D3` | 차트 보조 조각, 연한 배경 |
| `red-accent` | `#E8344E` | 비교 막대의 두 번째 막대 (최소한으로 사용) |
| `text-dark` | `#222222` | 제목, 소제목 |
| `text-body` | `#666666` | 본문 |
| `text-muted` | `#999999` | 캡션, 영문 보조 문구 |
| `line` | `#E5E5E5` | 구분선, 표 줄, 차트 트랙 |
| `bg` | `#FFFFFF` | 슬라이드 배경 |
| `chip-dark` | `#333333` | 어두운 알약형 라벨(우측 상단 태그, "Check" 원) |

규칙: 오렌지는 슬라이드 면적의 약 20% 이하로 쓰고, 차트를 제외하면 채도 높은 두 색을 나란히 두지 않습니다.

## 3. 타이포그래피

| 역할 | 폰트 | 크기 | 스타일 |
|---|---|---|---|
| 표지 제목 | Pretendard ExtraBold | 44–54 pt | 굵게 **이탤릭**, `text-dark` |
| 슬라이드 제목(헤더) | Pretendard ExtraBold | 18–20 pt | 굵게 이탤릭, 영문 대문자 가능 |
| 섹션 라벨 | Pretendard Bold | 13–14 pt | `primary-dark` 또는 `text-dark` |
| 본문(한글) | Pretendard / 맑은 고딕 | 11–12 pt | 보통, `text-body` |
| 캡션 / 영문 보조 문구 | Pretendard | 9–10 pt | 보통, `text-muted` |
| 큰 숫자(%) | Pretendard ExtraBold | 24–28 pt | `text-dark` |

- 대체 폰트: **맑은 고딕 (Malgun Gothic)**.
- 본문은 11 pt 이상으로 하고, 이보다 줄이지 말고 글을 줄입니다.
- 줄 간격 1.2–1.3. 본문은 왼쪽 정렬, 차트·아이콘 아래 글은 가운데 정렬합니다.

## 4. 레이아웃

**표지 슬라이드**
- 왼쪽 절반: 오른쪽 끝이 완전히 둥근 큰 "알약" 도형에 오렌지 톤 사진을 채우고 흰색 헤드라인을 올립니다.
- 오른쪽: 큰 이탤릭 제목 + 흐린 한 줄 부제.
- 장식: 배경의 가는 오렌지 사선, 오른쪽 끝의 가는 동심원, 작은 오렌지 링 마크.
- 왼쪽 하단: 발표자나 날짜용 작은 알약형 칩 2개(오렌지 / 어두운 색).

**본문 슬라이드 헤더 (모든 본문 슬라이드 공통)**
- 왼쪽 상단: "CONTENTS"가 적힌 작은 오렌지 태그(둥근 사각형), 이어서 이탤릭 슬라이드 제목, 그 오른쪽으로 가는 `line` 구분선.
- 오른쪽 상단: 작은 어두운 알약형 칩(섹션 또는 페이지 라벨).
- 하단 가장자리를 따라 가는 오렌지 선.

**그리드와 간격**
- 여백: 좌우 0.5 in, 상하 0.4 in.
- 본문 영역은 위에서 약 1.1 in(헤더 아래)부터 시작합니다.
- 3열(카드 / 차트) 또는 2열(텍스트 + 시각 자료) 그리드를 쓰고, 열 간격은 0.3 in 이상으로 동일하게 둡니다.

## 5. 컴포넌트

| 컴포넌트 | 설명 |
|---|---|
| 아이콘 도넛 카드 | 아이콘이 든 흰 원을 오렌지 부분 링이 감싸고, 아래로 오렌지 삼각형 포인터, 그 아래 라벨 + 2줄 텍스트. 3개씩 사용. |
| 파이/도넛 차트 | 오렌지 + `primary-light` 조각, 가운데 흰 원에 "CONTENTS" 라벨, 위쪽에 작은 오렌지 아이콘 원. |
| 퍼센트 링 | 값을 나타내는 가는 오렌지 호, 안쪽에 큰 % 숫자, 아래 라벨로 이어지는 가는 지시선. |
| 이미지 원 | 큰 원형으로 자른 사진 주위에 작은 오렌지/흰 아이콘 원 배치, 왼쪽에 텍스트 항목. |
| 표 | 헤더 행은 굵게, 가는 `line` 줄. 한 **강조 행**은 `primary`로 채우고 흰 글씨. 점 평가 열. |
| 막대 비교 | 짧은 가로 막대(`primary`, `red-accent`)와 오른쪽 % 값, 항목을 묶는 꺾쇠 선. |
| Check 박스 | 오렌지 "Check" 탭 + 연회색 상자. 메모·요약용으로 슬라이드 하단에 배치. |
| 알약형 칩 | 완전히 둥근 작은 라벨, 오렌지 또는 `chip-dark`, 흰색 9 pt 글씨. |

## 6. 권장 / 금지

- **권장**: 슬라이드 하나에 메시지 하나, 항목은 최대 3–4개.
- **권장**: 아이콘, 차트, 텍스트를 공통 중심선에 맞춰 정렬.
- **권장**: 모든 본문 슬라이드에 같은 헤더 사용.
- **금지**: 그라데이션, 부드러운 흐림보다 진한 그림자, 3개 이상의 폰트 사용.
- **금지**: 글이 도형과 겹치거나 상자를 넘치는 것(`ppt-rule-v1` 참고).
