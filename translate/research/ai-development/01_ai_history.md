# 01. AI 발전의 역사

## 주요 이정표

| 시기 | 사건 | 의의 |
|---|---|---|
| 1950 | 앨런 튜링, "튜링 테스트" 제안 | "기계는 생각할 수 있는가?"라는 질문을 처음 체계화 |
| 1956 | 다트머스 워크숍 (매카시, 민스키, 로체스터, 섀넌) | "인공지능"이라는 용어 탄생, 학문 분야로 출범 |
| 1974–1980 | 1차 AI 겨울 | 기대에 못 미친 성과와 컴퓨팅 한계로 연구 자금 급감 |
| 1980년대 | 전문가 시스템 붐 | 규칙 기반 AI의 상업적 활용 |
| 1987–1993 | 2차 AI 겨울 | 전문가 시스템의 높은 비용과 취약성 드러남 |
| 1997 | IBM 딥블루, 가리 카스파로프에게 승리 | AI가 체스 세계 챔피언을 이김 |
| 2012 | AlexNet, ImageNet 대회 우승 (크리제브스키, 수츠케버, 힌턴) | 2위와 약 10.8%p 차이, 딥러닝 붐의 시작 |
| 2016 | 딥마인드 알파고, 이세돌에게 승리 | 기계에게 너무 복잡하다고 여겨졌던 바둑 정복 |
| 2017 | 논문 "Attention Is All You Need"에서 트랜스포머 발표 | 현대 대규모 언어 모델 모두의 기반 |
| 2022.11.30 | OpenAI, ChatGPT 공개 | 5일 만에 100만 명, 약 2개월 만에 1억 명 (당시 가장 빠르게 성장한 소비자 앱) |
| 2023.03 | GPT-4 공개 | 이미지와 텍스트를 입력받는 대규모 멀티모달 모델 |
| 2024 | 노벨 물리학상(홉필드, 힌턴)·화학상(허사비스, 점퍼, 베이커) | AI 연구와 AI 기반 발견에 처음으로 노벨상 수여 |
| 2024–2025 | 추론 모델 등장 (OpenAI o1, DeepSeek-R1 등) | 모델이 답하기 전에 단계적으로 "생각" |
| 2025–2026 | AI 에이전트 부상 | 질문에 답하는 단계에서 작업을 스스로 수행하는 단계로 전환 |

## 패러다임의 변화

1. **기호주의·규칙 기반 AI (1950년대–1980년대)**: 사람이 논리와 규칙을 직접 코딩
2. **머신러닝 (1990년대–2000년대)**: 통계 기법으로 데이터에서 패턴 학습
3. **딥러닝 (2012–)**: 다층 신경망, GPU, 빅데이터로 시각·음성 분야에서 돌파구 마련
4. **생성형 AI·파운데이션 모델 (2017–)**: 트랜스포머 기반 대형 모델이 텍스트, 이미지, 코드 등을 생성
5. **에이전트형 AI (2025–)**: 모델이 계획을 세우고 도구를 쓰며 여러 단계의 작업을 수행

## 핵심 시사점

AI의 역사는 "여름"(기대와 투자)과 "겨울"(실망과 자금 삭감)이 반복되는 흐름이었습니다. 지금의 붐이 이전과 다른 점은 세 가지 요소가 동시에 갖춰졌다는 것입니다. 방대한 데이터, 저렴한 병렬 연산(GPU), 규모를 키울 수 있는 구조(트랜스포머)입니다.
