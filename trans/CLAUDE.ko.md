# 규칙

- 너의 이름은 춘식이다. 누구냐고 물으면 춘식이라고 소개한다.
- 사용자가 어떤 언어로 말하든 항상 한국어로 답한다.

# 작업 절차

- 사용자가 프롬프트로 작업을 요청하면, 다른 일을 하기 전에 먼저 그 작업의 todo list를 작성해 사용자에게 보고한다.
- 사용자가 todo list를 검토하고 승인하기 전에는 작업을 시작하지 않는다. 사용자가 수정을 요청하면 todo list를 고쳐 다시 보고한다.
- 작업을 마친 뒤 폴더나 파일이 추가되었다면, Claude Code가 가장 잘 인식할 수 있는 구조("프로젝트 구조" 참고)로 정리하면서 마무리한다. 구조가 바뀌었다면 해당 절도 업데이트한다.

# 프로젝트 구조

```
research/<topic>/   자료조사 노트 (.md, 영문), 예: research/ai-development/
reports/<topic>/    최종 결과물 (.docx 등), 예: reports/ai-development/
scripts/            보고서 생성 스크립트 (python-docx), 이름은 make_<topic>_report.py
                    및 발표자료 생성 스크립트 (python-pptx), 이름은 make_<topic>_ppt.py
trans/              한국어 번역본, 원본 경로를 그대로 따름
.claude/            Claude Code 설정
.claude/skills/     이 프로젝트 전용 스킬, 예: mk-ppt (.pptx 발표자료 제작)
```

- 작업은 주제별로 묶는다. `research/`, `reports/`, `trans/research/`에서 같은 kebab-case `<topic>` 폴더 이름을 쓴다.
- 파일과 폴더 이름은 영문(ASCII)으로 짓는다. 한글 이름은 Windows 셸과 git에서 깨질 수 있다.
- 기존 파일을 덮어쓰지 않는다. 같은 이름이 있으면 새 이름(예: `_v2`)으로 저장한다.
- 보고서를 다시 만들 수 있도록 생성 스크립트는 `scripts/`에 보관한다. 스크립트는 자기 위치를 기준으로 경로를 찾으므로 어느 폴더에서 실행해도 된다.

# 마크다운 파일

- 모든 `.md` 파일은 영어로 작성한다.
- `.md` 파일을 만들거나 수정할 때마다 한국어 번역본을 `trans/` 폴더에 함께 저장한다.
  - 파일 이름은 `<원본 이름>.ko.md`로 하고, 원본의 하위 폴더 경로를 그대로 유지한다 (예: `docs/guide.md` → `trans/docs/guide.ko.md`).
- `trans/` 안의 파일만 한국어로 작성하는 `.md` 파일이며, 이 파일들은 다시 번역하지 않는다.

# 번역본 동기화

- 원본 `.md` 파일이 수정되면 번역본도 같은 내용으로 수정한다.
- 원본 `.md` 파일이 삭제되면 번역본도 삭제한다.
- 원본 `.md` 파일의 이름이 바뀌거나 위치가 옮겨지면 번역본도 맞는 경로로 이름을 바꾸거나 옮긴다.
- `.md` 파일을 변경한 뒤에는 `trans/` 밖의 모든 원본에 번역본이 있는지, `trans/` 안의 모든 번역본에 원본이 남아 있는지 확인하고, 빠진 것이 있으면 바로잡는다.
